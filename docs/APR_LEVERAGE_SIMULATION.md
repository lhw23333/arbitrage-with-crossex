# APR 杠杆情景测算

入口：策略列表顶部参数面板 → **APR 测算杠杆（仅模拟）**。

未配置 Gate API key 时，可在设置向导点击 **仅浏览，稍后配置**，进入公开行情、APR 模拟和扫描诊断页面。浏览选择保存在当前浏览器，刷新仍有效；点击 **继续配置** 返回官方向导。浏览模式不挂载账户操作页面或交易面板，开仓按钮禁用，不自动读取账户仓位/挂单。它是界面模式，不会暂停已运行的后端任务，也不会改变服务器端的认证和交易权限检查。

- 默认「平台最高」，兼容原有测算；可选 1、2、3、5、10、15、20、25、50、100 倍。
- 每条永续腿的测算倍数 = min(所选倍数，该腿平台上限)。平台上限未知时不生成可信的 Capital / APR。
- 永续初始保证金 = 每腿名义金额 / 该腿测算倍数。Boros 的初始保证金仍按现有市场规则计算。
- Capital = 两条永续腿初始保证金 + 两条 Boros 腿初始保证金。
- 资金年化 APR = 预计净收益 / Capital × 365 / 剩余天数。
- 在名义仓位、成交价和成本假设相同时，改杠杆不改变预计利润，只改变 Capital、资金年化和排序。负收益情景下降杠杆也会缩小年化亏损的绝对值。

这是 **情景估算，不是实际账户收益审计**。Capital 未纳入额外闲置资金和安全缓冲；实际多投入的资金也应计入实际资金年化的分母。费用、滑点和到期假设仍沿用面板设置。

设置只写入浏览器的 `crossex.apr-simulation-leverage.v1`，通过只读 `GET /api/opportunities?perpLeverage=5` 参与测算及查询缓存键。返回的 `meta.perpLeverage` 标识该批卡片的假设；两腿明细显示各自测算倍数及平台上限。

**不会修改账户、已有仓位、下单参数或开仓向导。实际交易仍沿用原有平台最高杠杆逻辑。**
