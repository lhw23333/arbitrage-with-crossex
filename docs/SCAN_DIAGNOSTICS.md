# 扫描结果与盘口诊断

策略列表顶部新增「扫描结果与未展示原因」。这是一组只读诊断，不提供隐藏组合的下单入口。

- **亏损被过滤**：净资金 APR 可计算且为负，同时不在当前候选列表中。
- **数据缺失未展示**：不能完整报价的组合（也可能是订单簿深度不足），不等于亏损。
- **永续盘口诊断**：交易所、合约、读取阶段、错误类别、HTTP/网络错误码、耗时、检查时间和公开接口地址。
- **组合范围限制**：例如 Boros 市场没有 CrossEx 对冲交易场所。

分类按整批扫描而非用户的币种/平台筛选统计，另列筛选条件隐藏的数量。以实际候选列表为准，避免把收益接近零而暂时保留的组合、或按已有仓位重算后盈利的组合重复计入亏损分类。

盘口诊断与该次报价使用同一份缓存读取结果。失败依然返回空盘口，不用旧价格伪装成实时可交易报价，也不放宽开仓限制。原有交易估算调用仍得到 `NormalizedBook | null`，没有改变交易参数。
